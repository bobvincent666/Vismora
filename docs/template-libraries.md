# 工作流模板与提示词库

侧栏「配置与说明」新增「工作流模板配置」和「提示词库」。数据保存在当前浏览器的 IndexedDB；刷新和切换页面会保留，换浏览器或清除站点数据前请导出备份。

## 工作流模板

1. 点击「导入」，填写标题，通过下拉菜单选择单人、双人、换装等标签，填写描述并上传 JSON。也可以直接粘贴工作流 JSON。
2. API 格式会自动识别图片节点，分别确认人像、人物 B、服装、姿势和参考拼图的映射。不同图片槽位不能绑定同一节点。正向提示词默认保留文件中的内容。
3. 点击保存。列表支持搜索、标签筛选、排序、编辑、单条导出、原工作流导出及删除确认。
4. 点击「使用」，模板和映射加载到 AI工作台，使用本地 ComfyUI 协议。也可在工作台「工作流模板 (API 格式)」下拉框选择「我的模板」。选择模板后自动带入最近更新的关联提示词；有多条时可在「关联提示词」下拉框切换，也可恢复工作流原提示词。选择会保留到刷新后。确认图片和提示词后再生成，此操作不会自动生成图片。

画布格式同样可以保存、编辑和导出，但不能直接应用到合成台。请在 ComfyUI 中导出 API 格式，编辑模板并上传替换后的文件。

工作台默认仅保留模板选择、关联提示词、管理模板链接和「检查工作流兼容性」。导入统一在模板配置页完成；临时调试时，展开「高级参数」，在「工作流调试工具」中编辑 JSON 或导出当前调整后的工作流。

模板不保存已上传的人像照片；图片输入文件名会清空，应用后从合成台重新提供参考图。文件内的标准凭据字段与内嵌图片也不会进入备份。

## 提示词

支持直接新建，或导入 TXT 和本库导出的 JSON。字段包括标题、标签、描述、正向内容、可选反向内容、适用模型和关联工作流。创建、更新日期自动记录。

适用模型是备注，不会自动下载或切换模型。关联工作流后，「使用」会一并加载该模板及其节点映射，再填写提示词。没有关联时使用合成台当前配置。

图片编号应按工作流实际连线填写，不能仅依据网页槽位顺序。反向内容支持 Qwen 合并编码节点的 `negative_prompt` / `negative` 字段、含明确反向标题的独立文本节点，以及云端通义千问协议的反向参数；无法识别反向输入时会明确阻止应用，避免静默忽略。

## 检测与备份

- 「检测本机环境」读取 ComfyUI 的服务、节点及模型信息，不执行生成、不安装模型。工作流页检查库内模板；提示词页检查已关联的模板。
- 「整库导出」分别备份当前工作流库或提示词库。「从文件恢复 / 批量导入」恢复对应备份，遇到重复 ID 或标题可选择覆盖或保留副本。
- 将两个库迁移到另一浏览器时，先导入工作流库，再导入提示词库。首次导入保留记录 ID，可恢复模板关联；保留副本会获得新 ID，需要按需重新关联。
- 删除模板不会删除提示词；引用它的提示词会显示关联已删除，需要重新选择。
- 当前有任务生成时禁止通过库切换模板或提示词。库内保存、编辑与环境检测不消耗生图额度。
